# π0.5 数据预处理第一阶段

原始数据：50 条、30969 帧、17.20 分钟，LeRobot v2.1。

已完成：全部 Parquet 的结构与有限值检查；完整 episode 的 45/5 划分；仅用训练集计算 action/state 的 min、max、mean、std、q01、q99；每条动作步长和近静止时段汇总；原始元数据与 Parquet 的 SHA256。

验证条目：[0, 17, 26, 34, 44]。每十条按固定随机种子 42 选一条，不保证方块空间位置分层。训练 28083 帧，验证 2886 帧。

原始文件没有修改。没有裁切、删帧、重采样、转角度或重编码视频。近静止候选有 0 条，仅用于人工回看，不自动判错。用户已人工检查视频；本程序不重新验证视频解码或任务成功。

`train_numeric_statistics.json` 只包含数值字段统计，并非完整的 LeRobot `meta/stats.json`。不要直接用它覆盖原数据集元数据。训练时也不能只保留这份划分文件而继续把全部 50 条送入训练器。

还需完成：确定训练环境版本，转换数据副本到该版本支持的格式；让训练加载器实际使用 45 条训练和 5 条验证；按训练框架接入训练集统计、双相机映射和训练/推理一致的动作处理；验证真实 batch。图像 resize/pad、数值归一化与动作序列采样交由最终选定的训练处理器执行。

数据是 5 个关节位置 + 1 个夹爪，共 6 维；保留录制时的电机归一化数值，不按弧度/角度自行转换。模型内部 padding 不写进原始动作。

复现：`python prepare_pi05_data.py --root DATASET_ROOT --out NEW_OUTPUT_DIRECTORY --seed 42`。
